This repository helps learners understand important Java topics such as:

* Object-Oriented Programming
* Exception Handling
* Multithreading
* Linked Lists
* Pattern Problems
* Mathematical and Logic-based Problems

# ▶️ How to Run

### Clone the repository

```
git clone https://github.com/PoojaKanagaraj06/Java-Fundamentals.git
```

### Move into the directory

```
cd Java-Fundamentals
```

### Compile the program

```
javac FileName.java
```

### Run the program

```
java FileName
```
