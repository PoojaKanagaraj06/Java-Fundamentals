# Java Fundamentals ☕

This repository contains **core Java programs** written to strengthen fundamental programming concepts.
It is intended for **beginners, students, and interview preparation**, covering logic building and problem-solving using Java.

---

## 📌 Topics Covered

* Basic Java Syntax
* Data Types & Variables
* Operators
* Conditional Statements (`if`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Methods & Functions
* Arrays
* String Handling
* Number Programs

  * Armstrong Number
  * Prime Number
  * Neon Number
  * Strong Number
* Pattern Programs (Star & Number Patterns)
* Basic Mathematical Problems

## ▶️ How to Run the Programs

1. Install **Java JDK**
2. Clone the repository:

   ```bash
   git clone https://github.com/your-username/JavaFundamentals.git
   ```
3. Compile the program:

   ```bash
   javac FileName.java
   ```
4. Run the program:

   ```bash
   java FileName
   ```
